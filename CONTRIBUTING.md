# Contributing to StudyOS

Thanks for helping improve StudyOS.

## Development

StudyOS is a plain HTML, CSS, and JavaScript application. Keep changes dependency-free unless there is a clear reason to add a build tool.

1. Create a branch for your change.
2. Keep exam and career experiences separate.
3. Do not add fabricated BTEUP claims, video titles, channels, exam dates, or URLs.
4. Check the app in a desktop and mobile viewport.
5. Verify that navigation, local progress persistence, and external links still work.
6. Open a pull request with a short description and testing notes.

## Content guidelines

- Prefer beginner-friendly explanations.
- Clearly distinguish verified information from general recommendations.
- Do not expose API keys, passwords, or private user data.
- Keep the terminal visual style readable and accessible.
